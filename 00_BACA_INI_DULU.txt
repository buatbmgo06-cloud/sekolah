⚡ QUICK START (3 Langkah)
═══════════════════════════════════════════════════════════════

1. Cek Node.js:
   node -v
   npm -v
   
   (Jika error, install dari nodejs.org)

2. Install dependencies:
   cd sekolah-app
   npm install

3. Jalankan aplikasi:
   npm run dev
   
   Buka: http://localhost:3000

🎉 SELESAI!

⚠️ CATATAN PENTING
═══════════════════════════════════════════════════════════════

1. Node.js Wajib:
   Aplikasi ini membutuhkan Node.js versi 18 atau lebih baru.
   Download dari: https://nodejs.org

2. Mock Data:
   Saat ini menggunakan data statis di lib/mock-data.ts
   Untuk produksi, ganti dengan database (PostgreSQL, MySQL)

3. Server Actions:
   Form PPDB saat ini hanya console.log data
   Untuk produksi, tambahkan database insert & email notification

4. Gambar:
   Menggunakan placeholder dari picsum.photos
   Untuk produksi, upload ke CDN (Cloudinary, Vercel Blob)

🐛 TROUBLESHOOTING CEPAT
═══════════════════════════════════════════════════════════════

❌ Error: 'node' is not recognized
   → Install Node.js dari nodejs.org

❌ Error: Port 3000 already in use
   → npm run dev -- -p 3001

❌ Error saat npm install
   → Hapus node_modules dan reinstall:
     rm -rf node_modules package-lock.json
     npm install

❌ Dark mode tidak berfungsi
   → Clear cache browser (Ctrl+Shift+Delete)

❌ Gambar tidak muncul
   → Cek koneksi internet (gambar dari picsum.photos)
