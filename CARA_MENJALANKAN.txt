📋 CARA MANUAL (Pakai Terminal)
═══════════════════════════════════════════════════════════════

Jika script batch tidak berfungsi, gunakan cara manual:

1. Buka PowerShell atau Command Prompt

2. Masuk ke folder proyek:
   cd C:\Users\ferdi\suka\sekolah-app

3. Install dependencies (sekali saja):
   npm install

4. Jalankan website:
   npm run dev

5. Buka browser: http://localhost:3000

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ Error: "npm tidak dikenali"
   Solusi:
   - Restart komputer
   - Atau gunakan path lengkap:
     "C:\Program Files\nodejs\npm.cmd" install
     "C:\Program Files\nodejs\npm.cmd" run dev

❌ Error: "Port 3000 sudah digunakan"
   Solusi:
   - Tutup aplikasi yang menggunakan port 3000
   - Atau edit start.bat, ganti baris terakhir dengan:
     "C:\Program Files\nodejs\npm.cmd" run dev -- -p 3001
   - Lalu akses: http://localhost:3001

❌ Error saat npm install
   Solusi:
   - Hapus folder node_modules (jika ada)
   - Hapus file package-lock.json (jika ada)
   - Jalankan ulang install.bat

❌ Website tidak muncul di browser
   Solusi:
   - Pastikan server sudah running (lihat terminal)
   - Cek apakah ada error di terminal
   - Coba akses: http://127.0.0.1:3000
