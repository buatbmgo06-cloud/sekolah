📋 LANGKAH CEPAT (3 Menit)
═══════════════════════════════════════════════════════════════

1️⃣  CEK NODE.JS
    ─────────────────────────────────────────────────────────
    Buka terminal, ketik:
    
    node -v
    npm -v
    
    ✅ Jika muncul versi → Lanjut ke langkah 2
    ❌ Jika error → Install Node.js dari nodejs.org
    
    📖 Panduan lengkap: Baca INSTALASI_NODEJS.md


2️⃣  INSTALL DEPENDENCIES
    ─────────────────────────────────────────────────────────
    cd C:\Users\ferdi\suka\sekolah-app
    npm install
    
    ⏱️  Tunggu 1-3 menit (download ~350 packages)


3️⃣  JALANKAN APLIKASI
    ─────────────────────────────────────────────────────────
    npm run dev
    
    🌐 Buka browser: http://localhost:3000
    
    🎉 SELESAI! Website sudah berjalan!

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ Error: 'node' is not recognized
   → Install Node.js dari nodejs.org

❌ Error: Port 3000 already in use
   → npm run dev -- -p 3001

❌ Error saat npm install
   → rm -rf node_modules package-lock.json
   → npm install

❌ Dark mode tidak berfungsi
   → Clear cache browser (Ctrl+Shift+Delete)
